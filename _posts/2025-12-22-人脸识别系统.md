## 3. 任务一：人脸识别系统设计

> **目标**：使用 PCA+SVM 构建人脸识别基线系统（不使用预处理）

### 3.1 算法原理

#### 3.1.1 PCA（主成分分析）

PCA 是一种**降维**技术，核心思想是找到数据方差最大的方向，将高维数据投影到低维空间。

**数学描述**：
- 设有 $n$ 张人脸图像，每张展平为 $d$ 维向量：$X = [x_1, x_2, ..., x_n]^T$
- 计算均值：$\mu = \frac{1}{n}\sum_{i=1}^{n}x_i$
- 计算协方差矩阵：$C = \frac{1}{n}(X-\mu)^T(X-\mu)$
- 特征值分解，取前 $k$ 个最大特征值对应的特征向量作为主成分

**特征脸（Eigenface）**：每个主成分可视化为图像，称为"特征脸"，代表人脸的某种变化模式。

#### 3.1.2 SVM（支持向量机）

SVM 寻找一个**最优超平面**，使得不同类别的样本间隔最大化。

- 使用 **RBF 核函数**：$K(x_i, x_j) = exp(-\gamma||x_i - x_j||^2)$
- 将低维不可分问题映射到高维空间求解

### 3.2 实现代码

#### 数据加载

```python
def load_flat_dataset(data_path, config):
    """加载平铺结构的数据集（AR, Feret）"""
    images, labels, label_names = [], [], {}
    raw_path = data_path / config['path']
    
    # 收集所有图片并按人分组
    all_files = list(raw_path.glob(config['pattern']))
    groups = defaultdict(list)
    for f in all_files:
        person_id = config['parse'](f)  # 提取人员ID
        groups[person_id].append(f)
    
    # 读取图像
    for idx, (person_id, files) in enumerate(sorted(groups.items())):
        label_names[idx] = person_id
        for f in files:
            img = cv2.imread(str(f), cv2.IMREAD_GRAYSCALE)
            if img is not None:
                img = cv2.resize(img, config['img_size'])
                images.append(img)
                labels.append(idx)
    
    return np.array(images), np.array(labels), label_names
```

#### 构建 PCA+SVM 分类器

```python
def build_pca_svm(n_components=100):
    """构建 PCA + SVM 流水线"""
    return Pipeline([
        ('scaler', StandardScaler()),           # 标准化
        ('pca', PCA(n_components=n_components,  # PCA降维
                    whiten=True, random_state=42)),
        ('svm', SVC(kernel='rbf', C=10,         # SVM分类
                    gamma='scale', random_state=42))
    ])
```

#### 训练与测试

## 4. 任务二：光照鲁棒性提升

> **目标**：在任务一基线系统上，引入预处理方法提升识别性能

### 4.1 问题分析

任务一中 Feret 数据集准确率仅 66.85%，分析发现数据存在**光照差异**。通过引入预处理方法，可以消除光照影响，提升识别性能。

### 4.2 预处理方法

#### 方法1：直方图均衡化

```python
def preprocess_hist_eq(img):
    """直方图均衡化 - 增强对比度，消除光照不均匀"""
    return cv2.equalizeHist(img)
```

**原理**：将像素值重新映射，使灰度分布更均匀。

#### 方法2：CLAHE

```python
def preprocess_clahe(img):
    """CLAHE - 分块自适应均衡化，避免过度增强"""
    clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
    return clahe.apply(img)
```

**原理**：将图像分成8×8小块，每块单独均衡化。

#### 方法3：Gamma校正

```python
def preprocess_gamma(img, gamma=0.5):
    """Gamma校正 - 非线性调整图像亮度"""
    inv_gamma = 1.0 / gamma
    table = np.array([(i / 255.0) ** inv_gamma * 255 
                      for i in range(256)]).astype("uint8")
    return cv2.LUT(img, table)
```

**原理**：gamma < 1 提亮暗部，gamma > 1 压暗亮部。

### 4.5 结果分析

#### 汇总

| 数据集 | 基线(无预处理) | 最佳方法 | 提升 |
|--------|----------------|----------|------|
| AR | 98.40% | CLAHE: 98.50% | +0.10% |
| **Feret** | **66.85%** | **直方图均衡化: 70.92%** | **+4.08%** |
| Video | 98.33% | - | - |

#### 为什么 Feret 提升最明显？

1. **基线较低（66.85%）**：说明原始数据存在较大的光照差异
2. **直方图均衡化的作用**：
   - 将不均匀的灰度分布拉伸为均匀分布
   - 消除不同图像间的光照差异
   - 使特征更具有可比性

#### 为什么 AR 和 Video 提升不明显？

- 基线已经很高（98%+），说明原始数据质量很好
- 额外预处理可能引入噪声，反而略微降低性能

### 4.6 任务二结论

- 对于**光照差异较大**的数据集（如Feret），直方图均衡化可显著提升性能（**+4.08%**）
- 对于**质量较好**的数据集（如AR、Video），预处理提升有限
- **结论**：预处理方法的选择需要根据数据特点

## 5. 任务三：实验室与自然环境对比分析

### 5.1 实验室环境特点

本实验使用的三个数据集都是在**受控环境**下采集的：

| 特点 | AR | Feret | Video |
|------|-----|-------|-------|
| 光照 | 受控光源 | 受控光源 | 室内固定光源 |
| 姿态 | 正面为主 | 多角度但受控 | 视频连续帧 |
| 背景 | 纯色背景 | 纯色背景 | 复杂背景 |
| 质量 | 高质量 | 高质量 | 中等质量 |

### 5.2 自然环境的挑战

实际应用（手机解锁、监控识别）面临的问题：

| 挑战 | 描述 |
|------|------|
| 光照变化 | 室外阳光、室内灯光、逆光、阴影 |
| 姿态变化 | 侧脸、低头、抬头 |
| 遮挡问题 | 口罩、眼镜、头发 |
| 年龄变化 | 跨年龄识别 |
| 图像模糊 | 运动模糊、对焦不准 |

### 5.3 算法设计的区别

| 方面 | 实验室环境 | 自然环境 |
|------|------------|----------|
| 预处理 | 简单（灰度化、resize） | 复杂（人脸检测、对齐、增强） |
| 特征 | 全局特征（PCA） | 深度特征（CNN自动学习） |
| 模型 | 简单分类器（SVM） | 深度神经网络 |
| 训练数据 | 几千张 | 百万级别 |
| 数据增强 | 不需要 | 必须（旋转、翻转、噪声） |

### 5.4 改进方向

1. **更好的预处理**：自适应预处理、深度学习去噪
2. **更鲁棒的特征**：局部特征（SIFT, LBP）、稀疏表示
3. **深度学习**：CNN特征提取（VGGFace, FaceNet, ArcFace）
4. **多模态融合**：RGB + 深度图、人脸 + 声纹

## 6. 创新方法：自适应多策略预处理

### 6.1 创新思路

传统方法对所有图像使用**固定的预处理策略**，但不同图像的退化程度不同。

**核心创新**：根据图像亮度**自动选择**最佳预处理方法。

```
┌─────────────────────────────────────────────────────────┐
│              自适应多策略预处理流程                       │
├─────────────────────────────────────────────────────────┤
│  输入图像 → 计算平均亮度 → 判断亮度等级 → 选择预处理策略  │
│                                                         │
│  亮度等级判断：                                          │
│    • 亮度 < 50  (极暗)  → Gamma校正 + 直方图均衡化       │
│    • 亮度 < 100 (较暗)  → 直方图均衡化                   │
│    • 亮度 < 180 (正常)  → CLAHE                          │
│    • 亮度 ≥ 180 (过亮)  → 不处理                         │
└─────────────────────────────────────────────────────────┘
```

### 6.2 实现代码

```python
def adaptive_preprocess(img):
    """自适应多策略预处理"""
    mean_brightness = np.mean(img)
    
    if mean_brightness < 50:
        # 极暗图像：先Gamma校正提亮，再直方图均衡化
        gamma_corrected = preprocess_gamma(img, gamma=0.4)
        return cv2.equalizeHist(gamma_corrected)
    
    elif mean_brightness < 100:
        # 较暗图像：直方图均衡化
        return cv2.equalizeHist(img)
    
    elif mean_brightness < 180:
        # 正常图像：CLAHE保留细节
        clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
        return clahe.apply(img)
    
    else:
        # 过亮图像：不处理
        return img
```

### 6.3 实验设计

为验证创新方法，设计了**混合干扰**测试场景：

```python
def add_mixed_disturbance(img):
    """添加混合干扰：暗光 + 噪声 + 模糊"""
    # 1. 降低亮度到40%
    img = (img * 0.4).astype(np.uint8)
    # 2. 添加高斯噪声
    noise = np.random.normal(0, 15, img.shape)
    img = np.clip(img + noise, 0, 255).astype(np.uint8)
    # 3. 轻微模糊
    img = cv2.GaussianBlur(img, (3, 3), 0)
    return img
```

**为什么自适应方法更好？**

2. **避免过度处理**：正常图像不需要激进的均衡化
3. **可扩展性**：可根据不同场景添加更多策略

## 7. 实验总结

### 7.1 主要结论

| 任务 | 方法 | 关键结论 |
|------|------|----------|
| **任务一** | PCA+SVM (无预处理) | 基线系统：AR 98.40%, Feret 66.85%, Video 98.33% |
| **任务二** | 预处理方法对比 | Feret 通过直方图均衡化提升 **+4.08%** |

| **创新方法** | 自适应预处理 | 相比传统方法提升 **+0.54%** |

### 7.2 收获与体会

1. **理论与实践结合**：PCA、SVM 的数学原理在人脸识别中得到验证
2. **预处理的重要性**：简单的直方图均衡化可显著提升光照不均数据的性能
3. **算法选择**：没有"万能"算法，需要根据数据特点选择
4. **创新思维**：从"固定策略"到"自适应策略"是重要的改进方向

### 7.3 不足与展望

**局限性**：
- 数据集规模较小
- 只测试了光照变化，未测试姿态、遮挡等
- 未使用深度学习方法

**未来方向**：
- 引入 CNN 特征提取（VGGFace, ArcFace）
- 测试更多干扰类型（姿态、遮挡、模糊）
- 实现端到端的自适应预处理网络
